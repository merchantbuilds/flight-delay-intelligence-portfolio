# Flight Delay Intelligence & Airport Performance Analyzer

## Project Overview
An aviation data analytics project focused on analyzing flight delays, airline performance, and airport operations using Python, SQL, and Power BI.

## Tools & Technologies
- Python
- SQL / MySQL
- Microsoft Power BI
- Microsoft Excel
- Google Colab

## Project Objectives
- Analyze flight delay patterns.
- Evaluate airline performance.
- Examine airport operational performance.
- Present insights through interactive dashboards and visualizations.

## Key Skills Demonstrated
- Exploratory Data Analysis (EDA)
- Data Cleaning and Aggregation
- SQL Querying
- Data Visualization
- Dashboard Development
- Analytical Reporting
